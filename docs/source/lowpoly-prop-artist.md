# 雕塑类道具的低模规则（重点）

雕塑类道具（类型 B）的低模**不追求完美布线，允许并推荐直接使用三角面**。原因：这类道具不做动画变形，不需要再细分，最终效果主要靠高模烘焙出的法线贴图，低模只负责轮廓（剪影）和承载 UV。

可以接受：
- 全三角面网格，布线方向不规则
- 直接用自动减面工具生成：ZBrush **Decimation Master**、Blender **Decimate（Collapse）**、Maya **Reduce**、3ds Max **ProOptimizer**、Instant Meshes、Simplygon
- 面密度不均匀：剪影边缘、凸起处密，平坦/背面/看不到的地方稀

仍然必须满足（三角面 ≠ 随便做）：
1. **剪影优先**：从主要观看角度看，低模轮廓与高模误差肉眼不可见；凹凸起伏大的地方保留足够面。
2. **不包裹高模过紧也不过松**：低模应大致贴合高模表面，烘焙笼（Cage）能完整包住高模，避免投射丢失。
3. **避免极端细长三角**：长宽比过大的碎面会导致法线烘焙出现条纹和着色错误，减面后检查并局部手动修正。
4. **无错误几何**：无非流形边、无重叠面、无零面积面、无翻转法线、无孤立点。
5. **底面 / 贴墙面删除**：放在地面或贴墙看不到的面直接删除，不浪费面数和 UV。
6. **面数按结构分配（重要）**：
   - **平面/起伏少的区域面数要精简**：大平面、缓坡、只有浅雕刻（交给法线贴图）的区域，用尽量少的大三角面覆盖。
   - **面数集中在边缘结构和剪影上**：倒角边、石块分缝、崩口、轮廓外沿、从主要视角能看到的剪影线，优先保留面数。
   - 减面时用曲率/角度权重（如 Blender Decimate 的顶点组权重、ZBrush Decimation 的 Keep Groups/画 Mask）保护高曲率区域。
7. **不要出现转折交错的面**：
   - 边线要**顺着结构转折走**，三角面的对角线不能横跨转折线（例如倒角棱线被一条斜边切断，造成锯齿或明暗交错）。
   - 不允许折叠面、相邻面法线夹角突变（> 150° 的"折回"三角）、翻转面。
   - 减面后检查并**翻转对角线（Rotate Edge / Turn Edge）**，选择与高模表面更贴合的那条对角线。
8. **软硬边**：有机雕塑整体设为**软边（一个平滑组）**；只有明显的硬转折（如雕像底座的切角）才设硬边，并在硬边处断开 UV。
9. **UV 仍需认真处理**：三角面低模也要合理拆 UV（见「UV 拆分」），切缝尽量放在背面/凹陷/遮挡处。

推荐雕塑道具低模流程：
1. ZBrush 高模完成 → 在 ZBrush 内复制一份
2. Decimation Master：Pre-process → 按目标面数（如 3000–8000 三角面）Decimate，勾选 Keep UVs（若高模无 UV 则不勾）
3. 导入 DCC 软件 → 删除底面 → 检查剪影 → 局部清理细长三角和碎面
4. 检查平面区域是否还有多余的面（继续精简），边缘/剪影是否保留足够面
5. 检查转折处对角线走向，翻转横跨转折的边（Rotate/Turn Edge）
6. 统一软边 → 拆 UV（Blender 推荐 Zen UV：按角度标记接缝 → 展开 → 统一 300 px/m → 打包）→ 进入烘焙

# 完整制作流程

## 1. 准备与分析
- 收集参考图 / 原画，确认：道具用途、在场景中的位置、**镜头距离**（近景 / 中景 / 远景）、是否可交互、是否需要破碎。
- 确定道具分类（A/B/C）和**面数预算**（见下表）。
- 确定贴图规格：尺寸、是否共用材质 / Trim Sheet / 图集。

### 面数预算参考（三角面数）
| 体量 / 重要度 | 硬表面道具 | 雕塑类道具 |
|---|---|---|
| 小件（杯子、书、瓶子） | 100 – 800 | 300 – 1,500 |
| 中件（椅子、箱子、桶、小雕像） | 500 – 3,000 | 1,500 – 6,000 |
| 大件（柜子、马车、大雕像） | 2,000 – 10,000 | 5,000 – 20,000 |
| 主视觉 Hero 道具 | 10,000 – 30,000 | 15,000 – 50,000 |

> UE5 开启 Nanite 时雕塑类可大幅放宽，但仍建议提供常规低模作为 Fallback / 移动端版本。

## 2. 高模（如需要）
- 硬表面：Sub-D 或倒角 + 加权法线方案；细节（螺丝、刻字）可用浮动面片（Floater）烘焙。
- 雕塑：ZBrush 雕刻，细节层级到位，保持高模比例与低模一致。

## 3. 低模制作
**硬表面（A / C 类）**
- 以四边面为主，结构线跟随形体转折，导出前可三角化。
- 每条边都要"有用"：只保留影响剪影或着色的边，平面上不留无用循环边。
- 圆柱段数按大小与镜头距离：小件 8–12，中件 12–16，大件 / 近景 16–32。
- 看不到的面（底面、贴墙面、被遮挡的内侧）删除。
- 小倒角可选用**加权法线（Weighted Normals）**代替法线烘焙，节省贴图。
- 避免 N-gon（五边及以上的面）直接导出；避免 T 型连接导致着色异常。

**雕塑类（B 类）**
- 见上方「雕塑类道具的低模规则」—— 三角面即可，重在剪影、无错误几何和良好 UV。

**通用**
- 真实比例建模，单位统一。
- Pivot（轴心点）放在底部中心（贴墙道具放在背面底部中心），模块化道具对齐网格。
- 冻结变换 / 重置 XForm，缩放为 1，旋转为 0。

## 4. 平滑组 / 软硬边
- 规则：**硬边处必须断开 UV**；UV 断开处可以是硬边也可以是软边。
- 硬表面：约 > 60–80° 的转折设硬边，或全部软边 + 加权法线 / 法线贴图修正。
- 雕塑类：UV 岛内软边，**UV 接缝处设硬边**（每个 UV 岛一个光滑组，相邻岛不同组），烘焙法线时不出黑边；法线随 FBX 一起写出。
- UV 接缝放隐蔽处：结构缝隙（石缝）、底面、内侧、转角棱线；平整大面中间不切。
- 导出时勾选 Smoothing Groups，并导出 Tangents & Binormals（或在引擎内与烘焙器使用相同的 MikkTSpace 切线空间）。

## 5. UV 拆分
- UV 范围在 0–1 之内（除非刻意使用 Tiling / Trim Sheet）。
- **UV 拆分要合理（整合与利用率平衡）**：既不能碎，也不能为了"少岛"强行整合。先按结构块拆（每块拆成正面、背面、侧面等几个主岛，接缝走石缝和明显转折、放在内侧/不显眼处），然后**看利用率调整**：弯曲成弧形、细长、L 形等难排的岛（外接矩形填充率低于约 0.8）沿中间或转折处再切一刀，变成更方正好排的块；已经方正的岛不要再切。禁止大量碎小岛，岛数量以"刚好能排满"为准（参考：5000 三角面的石块类道具约 30–50 个岛）。
- **UV 要布满（较高的利用率）**：每张贴图都要打包铺满（按岛的真实形状紧密排列、允许 90° 旋转，而不是按外接矩形排，只保留规定 Padding），覆盖率目标 ≥ 65%；如果整合后覆盖率上不去，就按上一条切开难排的岛再打包，直到覆盖率达标或再切也不提高为止；切开后覆盖率反而下降的就退回不切（切一刀至少要换来约 1% 的利用率）。铺满后像素密度 ≥ 300 px/m 即合格（可以高于 300），低于 300 则按「贴图尺寸与张数」拆成多张，每张单独铺满。
- **Texel Density 统一为 300 px/m**（同一道具内、不同道具之间保持一致），重要可见面可适度放大，底部/背面可缩小。
  - 在 Maya（UV Toolkit → Texel Density）/ Max（Textools）/ Blender（Texel Density Checker）/ RizomUV 中设置 300 px/m 与对应贴图尺寸后统一缩放 UV。
  - 贴图尺寸按道具尺寸反推：贴图边长 ≈ 300 × 展开后 UV 覆盖的边长(m) ÷ UV 利用率，再取最接近的 2 的幂（256 / 512 / 1024 / 2048）。
- **贴图尺寸与张数（硬性规定）**：
  - 单张贴图**最大 2048×2048**，不允许使用 4096 或更大。
  - 贴图张数由像素密度决定：一张 2048 在规定 Padding 下打包后达不到 300 px/m，就拆成 **2 张**；2 张仍达不到就 **3 张**，以此类推，直到每张都 ≥ 300 px/m。
  - 估算张数：所需像素面积 = 模型表面积(m²) × 300²；单张可用面积 = 2048² × 实际 UV 利用率；**张数 = 向上取整(所需面积 ÷ 单张可用面积)**。
    - 例：表面积 21 m² → 需要 21 × 90,000 ≈ 1.89M px²；2048² × 41% ≈ 1.72M px² → 1.1 → **2 张**。
  - 多张拆分方式：按结构/石块等自然分组把 UV 岛分到不同贴图（每张对应一个材质 ID，命名 `M_道具名_01`、`M_道具名_02`…，贴图 `T_道具名_01_D` …），每张都要单独满足 300 px/m 和 Padding；尽量让每张利用率均衡。
  - 不允许为了凑一张贴图而缩小像素密度，也不允许压缩 Padding（2048 ≥ 16 px）来硬塞。
  - 只需要一张且用不满 2048 时，可以降到 1024 / 512（仍保证 300 px/m），或与其他道具共用图集。
- 切缝放在：硬边处、视线背面、凹槽内、被遮挡处。
- 拉伸检查：棋盘格贴图无明显拉伸、扭曲。
- 对称或重复部件可**重叠 UV**以节省空间，但重叠部分要在烘焙时移出 0–1（偏移整数 U）避免烘焙错误。
- 岛屿间距（Padding）：
  - 512 贴图 ≥ 4 px，1024 ≥ 8 px，2048 ≥ 16 px（贴图最大 2048）
- UV 利用率目标：≥ 70%（硬表面可达 80%+）。
- UV 岛尽量横平竖直摆放（直边岛屿拉直），减少锯齿。
- 第二套 UV（Lightmap UV，UE 中 Channel 1）：不重叠、无翻转、间距充足；可在引擎自动生成或手动制作。

## 6. 烘焙准备
- 高低模位置对齐，名称对应（`xxx_low` / `xxx_high`），多部件分组烘焙防止投射穿插（或 Explode 炸开烘焙）。
- 设置 Cage 或合适的投射距离，检查漏投射、错位。
- 烘焙贴图：Normal、AO、Curvature、ID（颜色 ID）、Thickness、Position、World Space Normal。
- 检查法线贴图：无接缝明显、无波纹条纹、无投射错误。

## 7. 命名与导出规范
命名（UE 习惯）：
- 静态网格：`SM_道具名_变体`，如 `SM_StoneStatue_A`
- 材质 / 材质实例：`M_` / `MI_`
- 贴图：`T_道具名_D`（BaseColor）、`_N`（Normal）、`_ORM`（AO/Roughness/Metallic 打包）、`_E`（Emissive）
- 高低模：`道具名_low`、`道具名_high`
- 名称使用英文，不使用中文、空格和特殊字符

导出：
- 格式 FBX（或 glTF，按项目要求）
- 勾选：Smoothing Groups、Triangulate（导出时三角化，保证引擎与烘焙一致）、Tangents & Binormals
- 不导出：相机、灯光、隐藏物体、历史记录
- 碰撞体（如需要）：`UCX_SM_道具名_01`，凸包，面数尽量低
- LOD：LOD0 原始；LOD1 ≈ 50%；LOD2 ≈ 25%；LOD3 ≈ 10%（雕塑类可直接用减面工具自动生成）

## 8. 引擎检查
- 导入后检查比例、轴心、朝向（前方 +X 或项目约定方向）。
- 检查法线方向、着色是否有黑斑或硬边异常。
- 检查光照贴图 UV 是否产生光照错误。
- 在实际场景镜头距离下看剪影和面数是否合适。

## 9. LOD
按下表制作，三角面数 = LOD0 三角面数 × 比例（例：LOD0 = 5000 → 4250 / 2500 / 1250 / 600）：

| LOD 级别 | 三角面数 | 占 LOD0 比例 | 切换屏幕占比 |
|---|---|---|---|
| LOD0 | LOD0 面数 | 100% | > 0.5 |
| LOD1 | × 0.85 | 85% | 0.25 – 0.5 |
| LOD2 | × 0.50 | 50% | 0.1 – 0.25 |
| LOD3 | × 0.25 | 25% | 0.03 – 0.1 |
| LOD4 | × 0.12 | 12% | < 0.03 |

- 减面用二次误差（QEM）类方法，优先保剪影：LOD1 去小细节和倒角，LOD2 只保主体轮廓，LOD3/LOD4 极简体；UV 接缝/材质边界加约束不被破坏，不允许法线翻转、UV 翻转。
- 所有 LOD 沿用 LOD0 的 UV 与贴图，**整个资产只有 LOD0 的材质 ID（例：2 个）**，各级 LOD 共用同一个多维材质，不得出现重复/改名的材质（如 `_ncl1_1`）。
- 报告每级实际三角面数、与 LOD0 的表面误差（平均 / 99% / 最大，cm），并出外形对比图。
- 命名 `道具名_LOD0` … `_LOD4`，平滑组同 LOD0 规则；引擎 Screen Size 依次 0.5 / 0.25 / 0.1 / 0.03（LOD4 用于 < 0.03）。

## 10. 碰撞体（Unreal）
- 按 UE「FBX Static Mesh Pipeline」：`UBX_`（盒，不可变形）/ `UCP_`（胶囊）/ `USP_`（球）/ `UCX_`（凸体），命名 `前缀_[渲染网格名]_##`，渲染网格名必须一致（有 LOD 时对应 LOD0 网格）。
- UCX 必须是完全封闭的凸体；凹形物体拆成多个凸包，凸包之间不相交、留小缝；单个凸包顶点 ≤ 32。
- 报告凸包数量、顶点数、相对渲染模型的外扩误差（平均 / 95% / 最大）。

## 11. 合并导出（UE）
- LOD 与碰撞放进同一个 FBX：LOD Group 节点（名 = 道具名）下按顺序挂 `_LOD0`…`_LOD4`；UCX 放在根层级。
- FBX 导出格式：**Binary，版本 FBX 2020（7.7）**，用 3ds Max 2024 自带 FBX 导出器导出（脚本 `max_fbx_export3.py`）；Max 脚本无法创建 LOD 控制器，导出后用 `fbx_patch_lod.py` 把组节点改为 LodGroup（其余字节保持 Max 原样）。
- 最终层级：
```
道具名                  ← LOD 组
 ├ 道具名_LOD0 … _LOD4
UCX_道具名_LOD0_##      ← 根层级
```
- 导入 UE：勾 Import Mesh LODs，关 Auto Generate Collision，关 Combine Meshes，Normal Import Method = Import Normals。
