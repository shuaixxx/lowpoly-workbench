| 原文主题 | 本次处理 | 原因 |
|---|---|---|
| 硬表面/静态雕塑/模块化 | 纳入 LP-001、002 | 一个组合资产的不同部件可以采用不同拓扑策略。 |
| 剪影、精简平面、沿结构走线 | 纳入 LP-004、005、007 | 保留目标形体；循环边需要有明确贡献。 |
| 面数预算和圆柱段数表 | 参考信息，当前预算优先 | 体量不能直接确定所有项目的面数。 |
| 曲率掩码和特征保护 | 与人工权重分开 | 曲率不是用户对玩法/全局重要性的标定。 |
| 重复面、退化面、孤点和非流形 | 纳入 LP-008 | 有意开放的边界需登记，不能把所有边界都报错。 |
| 细长面、翻面、法线夹角 150° | 纳入 LP-009 的诊断提示 | 缺少统一适用条件，不能作为自动删除标准。 |
| 删除隐藏面 | 条件采用 LP-010 | 还需考虑其他镜头、移动、阴影、破碎和烘焙用途。 |
| 小倒角可用加权法线代替法线烘焙 | 条件采用 LP-011 | 原文讨论法线方案；不应扩展成加权法线可以替代影响剪影的几何倒角。 |
| 单位、轴心、变换 | 纳入 LP-012，先检查再改 | 项目默认厘米不意味着可以盲目缩放已有场景。 |
| 高低模匹配与笼体风险 | 纳入 LP-014 的几何准备 | 真正的投射效果仍须实烘焙验证。 |
| UV、密度、分辨率、Padding、贴图 | 保留原文，移交后续阶段 | 不是本次几何 Skill 的自动任务或门槛。 |
| LOD、碰撞、Max/FBX、引擎 | 保留原文，移交后续阶段 | 当前未验证这些工具链，且 LOD 比例/层数表述有冲突。 |

原文一处允许 UV 接缝为软边或硬边，另一处要求所有 UV 接缝为硬边。这里不擅自选定未来接缝政策；几何阶段先按结构和着色检查，进入 UV/烘焙阶段再确定一套可验证的法线方案。

人工重要性、碑形资产预算/对称、案例状态和分层验收来自项目对话约定，详见 [workflow.md](workflow.md)。`lowpoly-rules.json` 的 `source_lines` 按起止行成对记录，多个区间依次排列；它记录来源位置，不表示区间内每句话都成为无条件规则。

规则表属于可审阅的规范目录。当前程序只覆盖其中一部分诊断，手工和视觉检查尚不能被一个自动“通过”标记替代。
