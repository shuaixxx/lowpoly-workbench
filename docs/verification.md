# v0.1.1 的验证范围

此仓库记录可复现的工具试验，不宣称已完成实际项目资产的生产验收。

| 层级 | 已验证内容 | 边界 |
|---|---|---|
| Python 单元检查 | 6 项：结构筛选、坐标变换/编号变化、不同拓扑、评价状态、未赋值/0、无效数据与曲面描述 | 不证明视觉质量或语义理解。 |
| 来源完整性 | 原文 SHA-256、规则 ID、来源行号范围、JSON/Python 语法、仓库内部链接 | 不证明每条艺术规则已自动实现。 |
| Blender 5.0.1 | `setup_cage`、`ring`、`tube`、`add_ring`、`bridge`、`bridge_reduce`、`tri_count`、`bx_review.review` | 只验证本次调用子集，未覆盖全部 Scenario 功能或其他 Blender 版本。 |
| 文件重开 | 合成 `.blend` 重开，网格及空重要性通道保留 | 非用户生产资产。 |
| 预览 | 三个样本的正面/斜视角、中性光/线框 | 仅适配检查，用户艺术评价仍待完成。 |

三份可编辑四边面样本的控制面与实际三角面分别为 `32 / 64`、`64 / 128`、`60 / 120`。第四份是三角化对照。四个样本均为 `unreviewed`，`accepted` 为 0，未替用户绘制重要性。具体结果见 [report.json](../examples/scenario-002/report.json)。

## 已处理的兼容性问题

上游 `setup_cage` 会启用 `show_in_front`，在本次 Workbench 线框预览中导致实心物体遮住线框。个人 Skill 的 `review_meshes` 在生成预览时暂时关闭该显示选项，并在 `finally` 中恢复调用方状态。未修改上游代码，也没有因此修改交付源网格。

## 尚未验证或实现

- 实际项目的完整低模、人工权重标定后的面数方案、用户审阅。
- 实烘焙、UV 方案、材质贴图、碰撞、LOD 和引擎运行。
- 学习型检索、边界点对应与自动贴合、整件预算求解、自动归纳/批准规则。
- 所有相交/重复面、剪影和着色问题的完整自动检测。

仓库检查可用 `tools/verify_repository.py` 和安装说明中的单元命令重复执行。Blender 试验单独运行，不需要或打开用户资产。
