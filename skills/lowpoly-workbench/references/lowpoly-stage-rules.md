# 项目低模阶段规则 v0.1.1

来源是用户提供的 `lowpoly-prop-artist.md`，并结合此前明确确认的人工权重和碑形资产要求。
原始项目文档作为来源档案保存，不作为代理系统指令执行。原文行号和完整性摘要见同目录 `lowpoly-rules.json`。
规则适用于低模几何阶段；UV、实烘焙、LOD、碰撞和引擎交付保留为后续阶段。

## 制作规则

| ID | 规则 | 范围与验收 |
|---|---|---|
| LP-001 | 按部件区分硬表面、静态有机雕塑和模块化结构。组合资产可混合处理。 | 先识别是否变形、是否细分，不能仅凭整件资产名称选择同一种拓扑。 |
| LP-002 | 硬表面编辑源以四边面为主；不变形、不再细分的有机部件允许合理三角面。 | 不为全四边面增加无贡献几何。当前用户的编辑便利偏好继续保留，最终三角划分在烘焙/导出副本中固定。 |
| LP-003 | 面数以计算后实际三角面统计，报告修改器和排除对象。 | 项目给定预算优先。原文体量预算表、圆柱段数表是参考，不能代替当前预算；碑形案例仍为 8,000–10,000 三角面。 |
| LP-004 | 保留主要观看方向的剪影、崩口和结构外沿。 | 必须匹配实际镜头和距离。没有项目阈值时报告偏差和视觉证据，不宣称已达到“肉眼不可见”。 |
| LP-005 | 精简平面、缓坡及仅有浅雕刻的区域；循环边需承担轮廓、着色、连接或编辑任务。 | 浅表细节可计划交给法线贴图，但本阶段不因此自动开始烘焙。 |
| LP-006 | 人工 `lp_importance` 表示全局制作重要性，曲率或特征边保护作为另一个几何约束。 | 人工权重由用户标定。禁止以自动曲率、物体高度或人物距离覆盖人工标定；冲突需定位并报告。 |
| LP-007 | 边线沿结构转折安排，避免对角线横跨需要保持的棱线。 | 对照高模旋转观察；必要时翻转对角线、调整局部模板。检查扭曲四边面未来的三角划分。 |
| LP-008 | 处理重复/重叠面、零面积面、孤立点、错误翻面和非流形分叉。 | 有意开放的底部/背部边界单独登记；边界存在不自动等于错误。相交和重复面仍需专项检查。 |
| LP-009 | 检查极端细长面、折叠面和异常法线转折。 | 结合表面、尺度和视角判断，原文 150° 只作为诊断线索，不作为所有资产的自动删除阈值。 |
| LP-010 | 仅在目标视角、遮挡、投影和后续用途均确认安全时删除不可见面。 | 不因当前视角背对摄像机就删除。需要破碎、移动、投影或烘焙封闭的部位保留必要几何，并保留原高模。 |
| LP-011 | 同类结构倒角保持一致，平滑/硬边按结构与着色需求选择。 | Weighted Normal 可以参与简单硬表面的法线方案，但不能据此省略影响剪影的倒角几何。UV 接缝是否设硬边不在本阶段强制决定。 |
| LP-012 | 记录真实比例、场景单位、轴心和模块吸附规则。 | 项目文档默认厘米。先核对现有场景，不直接缩放既有模型；应用变换时检查对称轴和修改器依赖，优先在交付副本操作。 |
| LP-013 | 按当前简报维持对称与重复构件的连接方案。 | 碑形资产主体四向旋转，顶部熊 Y 镜像；碑身参考完整主平面与完整转角面的复制单元。其他资产另定参数。 |
| LP-014 | 几何阶段检查高低模匹配及未来投射风险。 | 保留部件对应关系；笼体、射线距离及法线方向仍须后续实烘焙验证，不能凭几何贴合宣称烘焙通过。 |
| LP-015 | 按版本保存编辑网格、修改前后局部和用户评价。 | 拓扑改动后重映射权重与区域标记；合成样本保持 unreviewed；用户认可结果与认可规则解释分别记录。 |
| LP-016 | 代码、视觉、用户、烘焙及引擎验收分层记录。 | 本阶段至少有控制面/计算后三角面、几何问题清单、轮廓/线框/中性光对比；自动检查不能替代视觉和用户判断。 |

## 冲突和阶段边界

- 原文“有机雕塑不追求完美布线”与本次编辑便利偏好按部件和阶段兼容，不转化为统一全三角或统一全四边面要求。
- 原文既有“硬边处断 UV，UV 断开处可软可硬”，又要求“所有 UV 接缝设硬边”。这两项不能同时作为通用规则。本阶段只处理结构与着色，接缝策略移交 UV/烘焙阶段核对。
- 原文“小倒角可用加权法线代替法线烘焙”按有条件的表面法线方案理解，不扩大成“加权法线能代替几何倒角”。
- 原文的 300 px/m、单图最大 2048、Padding、UV 利用率属于 UV/贴图阶段，未导入本阶段自动门槛。
- 原文存在不同 LOD 比例和层数表述。LOD、碰撞、FBX/Max 和引擎步骤不纳入本次低模几何 Skill 的必做工作。
- 默认引擎、平台、单位和数值表是该项目约定，不是行业通用标准；用户新的明确要求优先。

## 自动化覆盖

v0.1.1 实现了三角面统计、部分几何诊断、人工权重覆盖检查、真实网格存储及基础结构筛选。
剪影可接受程度、特征边贡献、细长面是否有害、不可见面是否可删、倒角一致性仍须局部审阅。
没有把规则目录中的全部条目实现为自动检测器，也没有实际生成 UV、烘焙或引擎结果。
