# 低模制作工作台

将用户的局部示范变成可检查的网格案例，并以人工区域权重约束制作。优先保留可编辑的源网格。

## 已确认的工作约定

- 区域重要性由用户标定，使用独立顶点组 `lp_importance`，范围 0–1。缺少赋值表示未知，显式的 0 表示低优先级。不得通过高度、距离人物、截图或物体名称自行填充用户权重。
- 权重用于分配可调整预算；必要轮廓、受保护特征边、连接边界和着色需求仍须检查。权重不足或与项目约束冲突时，先完成无依赖的检查，再指出具体缺失或冲突。
- 默认停留在低模几何阶段。考虑未来烘焙，但 UV、实际烘焙、贴图、引擎导出按用户当前范围执行，不自行扩展阶段。
- 制作中尽量保留四边面以便编辑，预算按修改器计算后的实际三角面统计。保留编辑源；进入烘焙/导出阶段时，在副本上固定一致的三角划分。
- 同类构件使用一致的倒角方案。结合结构判断，不用一个角度阈值代替所有倒角决策。
- 用户当前要求高于上游默认。角色细分、全四边面、统一密度、UV 或闭合要求均不得无条件套用到静态道具。
- 原高模、参考低模和人物保持可追溯；新版本写到明确的输出目录。后台试验用 factory startup，不在正在编辑的场景中试错。

## 开始工作

项目使用四集合模板时，先读 [references/template-collections.md](references/template-collections.md)：`高模` 用于查看物体关系和结构；`前后对称`、`四向对称` 提供对应部件的对称安排；`自行判断` 中的部件需结合结构判断。读取实际模板及对象关系后再制作，文件未找到时记录尚未核对，不以旧场景冒充模板。
以模板中用于该部件制作安排的对象划分决定低模合并：已经属于同一对象的部分对应一个低模对象；仍是不同对象的部分保持分开，即使接触、交叠或重合。对象合并不自动要求焊接网格或布尔融合；同集合、父子关系、共享网格数据也不等于同一对象。

先读 [references/lowpoly-stage-rules.md](references/lowpoly-stage-rules.md)。这是从用户项目文档提取并按制作阶段限定的规则；机器可读目录在 `references/lowpoly-rules.json`，其中规则声明不等于已实现自动检查。
读取当前软件版本、场景状态和已有要求，复用已有授权。将制作阶段、资产部件、排除项、预算统计口径、对称方式和权重来源写进项目简报。
`references/monument-profile.json` 只描述本次碑形资产案例，须核对场景对象后使用，不能成为所有资产默认预算。
当前模板的明确安排优先于历史资产参数；对称轴、原点与单元边界须从模板核对，不能仅凭集合名称套用旧参数。

## 几何执行

使用 Scenario 时读取已安装的 `scenario-blender-retopology/SKILL.md` 及其必需的 expert 指引。
通过 `scripts/scenario_runtime.py` 加载本地工具，先检查已验证能力，再选择环线、管状块、边界桥接、疏密过渡或局部贴合。
本机兼容性及调用例子见 [references/scenario-backend.md](references/scenario-backend.md)。

先在副本或局部样本上验证连接、轮廓和阴影，再扩展到整件资产。自动重拓扑是候选构造方式，需要相同验收；不得只因达到面数就接受。
`scripts/blender_bridge.py` 可建立空的重要性通道、导出选定面片和审计控制网格/计算后网格。导出几何按原始局部坐标存储，世界变换单独保存。
拓扑改变后，权重及区域标记须重新映射并核对，禁止用旧顶点/面编号直接解释新网格。

## 案例检索与更新

制作前按当前区域查询案例，规则修订也应能回到真实几何。
使用 [references/case-library.md](references/case-library.md) 的格式和命令；`scripts/mesh_cases.py` 提供本地 SQLite 入库和结构筛选。

- 检索替代布线时比较形状描述、边界环、面类型和用途；目标拓扑可以不同。可选锁定边界顶点数。
- 拓扑指纹用于去重和候选筛选，不是图同构证明，也不是布线质量评分。
- 展示匹配理由、未满足条件和仍需验证的局部连接。没有合适案例就标为探索性制作，先做局部试验。
- 原始案例、用户评价和规则版本分开保存。一次修改可产生候选规则，但用户认可结果不自动认可代理推测的全部原因。
- 自动试验样本必须标为 `unreviewed`；失败样本可保存为 `failed`。默认生产检索只取有用户评价依据的 `accepted` 案例。

## 验收和交付

分别报告脚本检查、Blender 实际运行、线框/中性光视觉检查、用户审阅、实烘焙、引擎检查。
几何阶段报告控制面、计算后三角面、边界/非流形、退化面、权重覆盖和修改器；有意开放的边界按当前部件判断。
展示局部轮廓、倒角、接缝及密度过渡，不以平均表面误差或检查通过代替视觉判断。
保存可打开的 `.blend`、网格案例和检查结果；交付时说明实际验证范围和待完成能力。

## v0.1 能力边界

现有实现包含真实网格数据保存、结构特征索引、局部重要性通道和 Scenario 调用适配。
尚未实现学习型相似度检索、通用子图匹配、自动模板拼接、用户权重驱动的整件预算求解或自动规则归纳。
独立试验入口是 `scripts/trial_scenario.py`，仅允许在后台 Blender 的空场景中运行。
